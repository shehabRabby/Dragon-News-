# 🐉 Dragon News

[🔗 Live Demo](https://dragon-news-firebase-d7ca5.web.app)

---

## 🧑‍💼 Professional Overview

**Dragon News** is a responsive **React.js** web application delivering real-time news across multiple categories via the **Programming Hero Open API**.  
It features a modern interface, smooth navigation, and **secure Firebase authentication**.

### Key Features
- Fetches real-time news from the Programming Hero API  
- Browse news by categories  
- Detailed article view (author info, publish date)  
- Firebase Authentication (Login & Register)  
- Fully responsive layout for all screen sizes  
- Modern UI/UX with **Tailwind CSS** + **DaisyUI**

### Tech Stack
- **Frontend:** React.js, JavaScript, HTML5, CSS3  
- **Styling:** Tailwind CSS, DaisyUI  
- **Routing:** React Router DOM  
- **Auth:** Firebase Authentication  
- **Icons:** React Icons  

> A modern, scalable, and visually appealing news platform for a smooth reading experience and secure user interaction.
